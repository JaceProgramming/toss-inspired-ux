# 한국어 UX 라이팅

한국어 화면 문구를 쓸 때 지키는 규칙이에요. 언어와 상관없는 원칙(다음 화면 힌트 주기, 군더더기 빼기, 에러 메시지 구조 등)은 `ux-writing.md`에 있고, 이 문서는 한국어에서만 생기는 어투·문법 문제를 다뤄요.

예문은 이 가이드에서 새로 쓴 것이에요.

**목차:** 다섯 가지 기본 규칙 · 예외 · 쉬운 말 고르기 · 제목과 버튼 · 숫자·날짜·단위 · 에러 문구 · 쓰지 않는 표현 · 자주 틀리는 표기 · 점검 목록

## 다섯 가지 기본 규칙

### 1. 해요체로 통일해요

화면 어디서든 같은 사람이 말하는 것처럼 들려야 해요. 합쇼체(~습니다, ~십시오), 반말, 명사로 끝나는 통보형 문장을 섞지 않아요. 버튼과 짧은 레이블은 명사나 "~하기"로 끝나도 괜찮아요.

| 이렇게 쓰지 않고 | 이렇게 써요 |
|---|---|
| 저장되었습니다. | 저장했어요. |
| 비밀번호를 입력해 주십시오. | 비밀번호를 입력해 주세요. |
| 삭제하시겠습니까? | 삭제할까요? |
| 로그인이 필요합니다. | 로그인하면 볼 수 있어요. |
| 주문 접수 완료 | 주문을 받았어요 |
| 인증번호 발송됨 | 인증번호를 보냈어요 |

### 2. 능동형으로 써요

누가 무엇을 했는지 드러나게 써요. "~되었습니다", "~됐어요"는 대부분 "~했어요"로 바꿀 수 있어요.

| 이렇게 쓰지 않고 | 이렇게 써요 |
|---|---|
| 송금이 완료됐어요. | 5만 원을 보냈어요. |
| 주소가 변경되었어요. | 주소를 바꿨어요. |
| 신청이 접수되었습니다. | 신청을 받았어요. |
| 예약이 취소 처리되었습니다. | 예약을 취소했어요. |
| 이미 신청했었어요. | 이미 신청했어요. |

"되어요"는 "돼요"로 줄여 써요. 짧고 말하는 것처럼 들려요.

### 3. 긍정형으로 써요

안 되는 것보다 할 수 있는 것을 말해요. 조건이 있다면 그 조건을 채우면 무엇을 할 수 있는지 알려 줘요.

| 이렇게 쓰지 않고 | 이렇게 써요 |
|---|---|
| 본인 인증을 하지 않으면 이용할 수 없어요. | 본인 인증을 하면 이용할 수 있어요. |
| 지금은 상담 시간이 아니에요. | 오전 9시부터 상담할 수 있어요. |
| 쿠폰이 없어요. | 첫 주문을 하면 쿠폰을 받을 수 있어요. |
| 8자 미만은 사용할 수 없어요. | 8자 이상으로 만들어 주세요. |
| 출고 후에는 배송지 변경이 불가해요. | 출고 전까지 배송지를 바꿀 수 있어요. |

다이얼로그에서 창만 닫는 버튼은 "취소"가 아니라 "닫기"예요. "취소"는 하던 일이 취소되는 것처럼 읽혀요.

### 4. 경어는 가볍게 써요

높임이 겹칠수록 문장이 길어지고 거리감이 생겨요. "~시~", "께", "계시다", "여쭈다", "드리다"를 꼭 필요한 곳에만 써요.

| 이렇게 쓰지 않고 | 이렇게 써요 |
|---|---|
| 입력하신 정보를 확인하시겠어요? | 입력한 정보를 확인할까요? |
| 궁금한 점이 있으시면 문의해 주시기 바랍니다. | 궁금한 점이 있다면 물어봐 주세요. |
| 고객님께 안내드립니다. | 알려드릴게요. |
| 아직 가입하지 않으신 분이 계신가요? | 아직 가입하지 않았나요? |
| 결제 금액은 5,000원이십니다. | 결제 금액은 5,000원이에요. |

사물에는 높임을 쓰지 않아요("상품이 도착하셨습니다" ✕). 높임을 빼서 어색해지면 사용자 대신 정보를 주어로 문장을 다시 써요("받으실 금액은" → "받는 금액은").

"고객님", "회원님" 같은 호칭은 반복하지 않아요. 부를 일이 있으면 "{이름}님"으로 한 번만 불러요.

### 5. 명사를 늘어놓지 말고 풀어 써요

한자어 명사를 이어 붙이면 공문서처럼 읽혀요. 동사로 풀어서 말하듯이 써요.

| 이렇게 쓰지 않고 | 이렇게 써요 |
|---|---|
| 본인 인증 완료 후 서비스 이용 가능 | 본인 인증을 마치면 이용할 수 있어요 |
| 결제 수단 등록 필요 | 결제 수단을 등록해 주세요 |
| 비밀번호 5회 오류 시 계정 잠금 | 비밀번호를 5번 틀리면 계정이 잠겨요 |
| 배송 지연 안내 | 배송이 조금 늦어지고 있어요 |
| 이용 약관 동의 후 가입 진행 | 약관에 동의하면 가입할 수 있어요 |

## 예외

규칙보다 명확함이 먼저예요. 아래 상황에서는 규칙을 벗어나는 편이 나아요.

**수동형이 나은 경우**
- 사용자에게 일어난 일을 강조할 때: "쿠폰이 만료됐어요", "서비스가 종료돼요"
- 원인과 결과를 분명히 해야 할 때: "비밀번호를 5번 틀려서 계정이 잠겼어요"
- 민감한 상황에서 안심시킬 때: "입력한 정보는 암호화돼서 저장돼요"

**부정형이 나은 경우**
- 정책상 이용할 수 없을 때. 이유를 함께 말해요: "만 14세 미만은 가입할 수 없어요. 보호자 동의가 필요해요."
- 일부 기능만 안 될 때. 되는 것이 아니라 안 되는 것을 정확히 짚어요: "지금은 해외 결제만 할 수 없어요."
- 불안을 줄여야 할 때: "돈은 빠져나가지 않았어요", "다른 사람에게 보이지 않아요"

**높임이 필요한 경우**
- 사용자의 상황을 짐작해서 물을 때: "혹시 이사하셨나요?"
- 호의나 양해를 구할 때: "잠시만 기다려 주시겠어요?"

## 쉬운 말 고르기

친구에게 말로 설명할 때 쓰지 않을 단어라면 바꿔요.

| 이 말 대신 | 이렇게 써요 |
|---|---|
| 송금, 이체 | 보내기, 옮기기 |
| 수취인 | 받는 분 |
| 금일 / 익일 / 익월 | 오늘 / 다음 날 / 다음 달 |
| 기재, 기입 | 입력, 적기 |
| 상이 | 다름 |
| 발급 | 받기, 만들기 |
| 조회 | 보기, 확인 |
| 수령 | 받기 |
| 납부 | 내기 |
| 차감 | 빠져요, 빼요 |
| 환급 | 돌려받기 |
| 소요 | 걸려요 |
| 유효하지 않은 | 맞지 않는, 쓸 수 없는 |
| 오류가 발생했습니다 | 문제가 생겼어요 |
| 재시도 | 다시 시도 |
| 활성화 / 비활성화 | 켜기 / 끄기 |
| 해당 | 이, 그 (또는 빼기) |
| ~에 한하여 | ~만 |
| ~을 통해 | ~로 |
| 및 | 와/과, 그리고 |
| 필히, 반드시 | 꼭 |

업계 용어를 꼭 써야 한다면 처음 나올 때 한 번 풀어 줘요. 같은 대상은 처음부터 끝까지 같은 이름으로 불러요.

## 제목과 버튼

**제목**
- 사용자에게 건네는 한 문장이에요. 물을 때는 "~할까요?", "~를 알려 주세요", 알릴 때는 "~했어요", "~할 수 있어요".
- 보통 글자 크기에서 두 줄을 넘기지 않아요.
- 명사형 제목("수취인 정보 입력")보다 문장형 제목("누구에게 보낼까요?")을 써요.
- 메뉴나 링크 이름에는 질문형을 쓰지 않아요. "어떤 서류가 필요한가요?"는 누가 묻는 것처럼 읽혀요. "필요한 서류 확인하기"로 써요.

**버튼**
- 누르면 일어나는 일을 써요: "5만 원 보내기", "주소 저장하기", "동의하고 시작하기".
- "확인" 하나로 때우지 않아요. 무엇을 확인하는지 드러나는 동사가 있으면 그걸 써요.
- 10자 안팎으로, 한 줄에 들어가게 써요.
- 동작 버튼은 "~하기"로 맞추고, "다음", "닫기"처럼 굳어진 말은 그대로 써요. 한 서비스 안에서 "저장"과 "저장하기"를 섞지 않아요.
- 창만 닫을 때는 "닫기", 진행 중인 일을 그만둘 때만 "취소"를 써요.
- 거절 버튼은 담백하게 써요: "다음에 할게요", "괜찮아요". 죄책감을 주는 말("혜택 포기하기")은 쓰지 않아요.

**띄어쓰기와 문장부호**
- "해 주세요"와 "해주세요"는 둘 다 허용돼요. 하나로 정해서 끝까지 지켜요.
- 느낌표와 말줄임표는 아껴 써요. 제목 끝에는 마침표를 찍지 않아요.

## 숫자·날짜·단위

- 아라비아 숫자와 단위는 붙여 써요: 10,000원, 3개, 5분.
- 세 자리마다 쉼표를 찍어요.
- 큰 금액은 "만", "억"으로 읽기 쉽게 써요: 1억 2,000만 원. 정확한 숫자가 필요하면 함께 보여 줘요.
- 할인은 비율보다 금액으로: "30% 할인"보다 "5,000원 할인".
- "최대 ~"보다 확실한 숫자를 써요: "최대 5만 원 할인"보다 "누구나 1,000원 할인".
- 날짜는 "10월 8일 (목)"처럼 쓰고, 올해가 아니면 연도를 붙여요. 가까운 날은 "오늘", "내일", "어제".
- 시간은 "오후 3시", "오전 9시 30분"처럼 써요.
- 기한은 끝나는 시각까지 정확히: "10월 8일 밤 11시 59분까지".
- 기간과 횟수는 숫자로: "곧"보다 "1분 안에", "여러 번"보다 "3번".

## 에러 문구

구조는 하나예요. **무슨 일인지 → (도움이 되면) 왜 그런지 → 지금 할 수 있는 일**, 그리고 그 일을 바로 해 주는 버튼.

| 상황 | 이렇게 쓰지 않고 | 이렇게 써요 |
|---|---|---|
| 입력값 | 잘못된 형식입니다. | 숫자 16자리를 모두 입력해 주세요. |
| 한도 | 한도 초과로 이체 불가 | 하루에 200만 원까지 보낼 수 있어요. 오늘은 50만 원 남았어요. |
| 인증 | 생체 인증 실패 | 지문을 읽지 못했어요. 비밀번호로 로그인할 수 있어요. |
| 네트워크 | 네트워크 오류 (E-1042) | 인터넷 연결을 확인해 주세요. 입력한 내용은 그대로 있어요. |
| 결제 | 결제에 실패하였습니다. | 이 카드로는 결제하지 못했어요. 결제된 금액은 없어요. |
| 점검 | 시스템 점검 중입니다. | 지금은 은행 점검 시간이에요. 오전 2시 30분부터 다시 할 수 있어요. |
| 내부 문제 | 알 수 없는 오류가 발생했습니다. | 문제가 생겼어요. 잠시 후 다시 시도해 주세요. |

- 사용자를 탓하지 않아요: "잘못 입력하셨습니다" 대신 "비밀번호가 맞지 않아요".
- "~해야 해요"보다 "~할 수 있어요"를 먼저 떠올려요.
- 오류 코드, 시스템 용어, 제휴사 용어를 그대로 보여 주지 않아요.
- "고객센터에 문의해 주세요"라고만 쓰지 않아요. 누르면 바로 문의할 수 있는 버튼을 줘요.
- 확실한 것만 약속해요. "결제된 금액은 없어요"는 정말 그럴 때만 쓰고, 결과를 알 수 없을 때는 "주문이 됐는지 확인하지 못했어요. 다시 시도해도 두 번 결제되지 않아요."처럼 써요.
- 누르기 전에 알 수 있는 문제(최소 주문 금액, 한도, 빈 칸)는 다이얼로그가 아니라 버튼 옆에 미리 한 줄로 알려 줘요.

## 쓰지 않는 표현

- **공포·압박:** "지금 안 하면 손해", "마지막 기회", "곧 마감" (실제 마감이 아닐 때)
- **죄책감:** "정말 포기하시겠어요?", "혜택을 버리시겠어요?"
- **과장:** 근거 없는 "최고", "최대", "무조건"
- **책임 떠넘기기:** "잘못 입력하셨습니다", "고객님의 실수로"
- **유행어·밈·줄임말:** 몇 달 뒤에는 통하지 않고, 누군가는 이해하지 못해요
- **내부 용어:** 팀 안에서만 쓰는 기능 이름, 영문 약어
- **무의미한 인사:** "안녕하세요, ○○입니다. 항상 이용해 주셔서 감사합니다." 로 시작하는 안내

## 자주 틀리는 표기

| 틀린 표기 | 맞는 표기 |
|---|---|
| 되요, 됬어요 | 돼요, 됐어요 |
| 할께요 | 할게요 |
| 않 돼요 | 안 돼요 |
| 몇일 | 며칠 |
| 바꼈어요 | 바뀌었어요 |
| 계좌에요, 통장예요 | 계좌예요, 통장이에요 |
| 결재했어요 (돈을 낼 때) | 결제했어요 |
| 메세지 | 메시지 |
| 컨텐츠 | 콘텐츠 |
| 어플 | 앱 |
| 할수있어요 | 할 수 있어요 |

받침이 있으면 "이에요", 없으면 "예요"를 써요. 이름이나 금액처럼 값이 바뀌는 자리 뒤에는 조사가 어긋나지 않게 문장을 짜요("{이름}님에게 보냈어요"처럼 받침과 상관없는 조사를 고르거나, 값에 따라 조사를 바꿔요).

## 점검 목록

문구를 소리 내어 읽어 본 다음 확인해요.

- 모든 문장이 해요체인가요? "~습니다", "~십시오"가 남아 있지 않나요?
- "~되었습니다"를 "~했어요"로 바꿀 수 있는 곳은 없나요?
- "없어요", "안 돼요", "불가"를 할 수 있는 일로 바꿔 말했나요?
- "~시~"가 한 문장에 두 번 이상 들어가지 않았나요?
- 한자어 명사가 세 개 이상 붙어 있지 않나요?
- 버튼만 읽어도 누르면 무슨 일이 일어나는지 알 수 있나요?
- 창을 닫는 버튼에 "취소"를 쓰지 않았나요?
- 에러마다 지금 할 수 있는 일이 적혀 있나요?
- 같은 대상을 한 가지 이름으로만 부르고 있나요?
- 숫자에 단위와 쉼표가 있나요?
